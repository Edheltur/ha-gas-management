# Gas Management

Пользовательская интеграция Home Assistant для ручного учёта остатка CO₂ по массе.
Каждый баллон добавляется отдельно и получает своё устройство, четыре поля ввода и
два сенсора.

## Установка

1. Скопируйте `custom_components/gas_management` из репозитория в каталог
   `/config/custom_components/` Home Assistant.
2. Перезапустите Home Assistant.
3. Откройте **Настройки → Устройства и службы → Добавить интеграцию → Gas Management** и
   задайте имя баллона. Повторите для каждого баллона.
4. На странице устройства введите массы в килограммах. Если на взвешивании нет съёмного
   оборудования, введите для него 0.

## Показания

| Поле | Что ввести |
| --- | --- |
| Масса пустого баллона | Тару без учитываемого съёмного оборудования |
| Масса установленного оборудования | Массу съёмного оборудования, присутствующего на весах |
| Текущая масса сборки | Массу баллона, газа и оборудования на весах |
| Номинальная масса заправки | Массу газа при номинальной заправке |

Диапазон ввода 0–1000 кг, шаг 1 г. Введённые массы хранятся отдельно для каждого
баллона и восстанавливаются из хранилища Home Assistant без участия Recorder.

Остаток в граммах равен разнице между массой сборки и суммой тары и оборудования,
умноженной на 1000. Заполнение считается относительно номинальной заправки и может
превышать 100%. При пропущенной массе или отрицательном остатке соответствующие
сенсоры недоступны. Нулевая или пропущенная номинальная заправка делает недоступным
только процент заполнения, если остаток уже можно вычислить.

[Готовый YAML дашборда](examples/dashboard.yaml) использует штатные карточки.
Вставьте его в редактор конфигурации отдельного дашборда и замените идентификаторы
сущностей на значения со страницы устройства. Для каждого следующего баллона
добавьте копию блока. График требует, чтобы Recorder записывал сенсор остатка.

## Разработка

Тесты используют Python 3.14 и Home Assistant Core из закреплённой версии тестового
плагина.

```sh
python3.14 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-dev.txt
ruff format --check .
ruff check .
python -m pytest
```
