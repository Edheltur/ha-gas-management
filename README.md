# Gas Management

[![Открыть Gas Management в Marketplace Home Assistant](https://my.home-assistant.io/badges/marketplace_repository.svg)](https://my.home-assistant.io/redirect/marketplace_repository/?owner=Edheltur&repository=ha-gas-management&category=integration)

Пользовательская интеграция Home Assistant для ручного учёта остатка CO₂ по массе.
Каждый баллон добавляется отдельно и получает своё устройство, четыре поля ввода и
два сенсора.

## Установка

Минимальная проверенная версия Home Assistant Core — **2026.10.4**.

**Home Assistant 2026.11 и новее**

1. Откройте **Настройки → Marketplace → Добавить по ссылке** (*Add from link*).
2. Введите `https://github.com/Edheltur/ha-gas-management`. Подключите GitHub,
   если Marketplace запросит это. Если потребуется указать тип, выберите
   **Интеграция**.
3. Откройте **Gas Management**, нажмите **Установить** и пройдите настройку.
   Перезапустите Home Assistant, если интерфейс предложит это.

**Home Assistant 2026.10.4 с HACS**

1. Откройте [Gas Management в HACS](https://my.home-assistant.io/redirect/hacs_repository/?owner=Edheltur&repository=ha-gas-management&category=integration).
   Или в HACS выберите **⋮ → Пользовательские репозитории**, добавьте
   `https://github.com/Edheltur/ha-gas-management` с типом **Интеграция** и
   откройте Gas Management.
2. Нажмите **Скачать** и перезапустите Home Assistant.

### Добавление баллона

Если настройка ещё не открыта, перейдите в **Настройки → Устройства и службы →
Добавить интеграцию → Gas Management**. Задайте имя баллона. Повторите для каждого
следующего баллона. На странице устройства введите массы в килограммах. Если при
взвешивании нет съёмного оборудования, введите для него 0.

## Показания

| Поле | Что ввести |
| --- | --- |
| Масса пустого баллона | Тару без учитываемого съёмного оборудования |
| Масса установленного оборудования | Массу съёмного оборудования, присутствующего на весах |
| Текущая масса сборки | Массу баллона, газа и оборудования на весах |
| Номинальная масса заправки | Массу газа при номинальной заправке |

Диапазон ввода 0–1000 кг, шаг 1 г. Введённые массы хранятся отдельно для каждого
баллона и восстанавливаются из хранилища Home Assistant без участия Recorder.

Остаток в граммах равен разнице между массой сборки и суммой тары и оборудования,
умноженной на 1000. Заполнение считается относительно номинальной заправки и может
превышать 100%. При пропущенной массе или отрицательном остатке соответствующие
сенсоры недоступны. Нулевая или пропущенная номинальная заправка делает недоступным
только процент заполнения, если остаток уже можно вычислить.

[Готовый YAML дашборда](examples/dashboard.yaml) использует штатные карточки.
Вставьте его в редактор конфигурации отдельного дашборда и замените идентификаторы
сущностей на значения со страницы устройства. Для каждого следующего баллона
добавьте копию блока. График требует, чтобы Recorder записывал сенсор остатка.

## Разработка

Тесты используют Python 3.14 и Home Assistant Core из закреплённой версии тестового
плагина.

```sh
python3.14 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-dev.txt
ruff format --check .
ruff check .
python -m pytest
```
